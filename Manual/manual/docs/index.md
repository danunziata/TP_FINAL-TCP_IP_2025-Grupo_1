# Manual de uso de Visualizador de Variables de equipo PowerLogic™ Circuit Monitor Series 4000

Éste manual contiene la información necesaria para una correcta manipulación de la aplicación web "", creada para visualizar parámetros provenientes del equipo PowerLogic™ Circuit Monitor Series 4000, instalado en el Instituto de Protecciones de Sistemas Eléctricos de Potencias (IPSEP) de la Universidad Nacional de Río Cuarto(UNRC).

En las diferentes pestañas de éste manual se puede observar, de manera ordenada en cómo vería la aplicación el usuario, las forma de proceder y de utilizar las opciones que presenta la aplicación.
